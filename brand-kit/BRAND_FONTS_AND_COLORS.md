## FONTS — identified in the supplied PDF files

The source PDFs contain embedded/subset fonts with these internal PostScript names:

- **Times New Roman Regular** — `TimesNewRomanPSMT` (embedded TrueType subset)
- **Helvetica Neue Medium** — `HelveticaNeue-Medium` (embedded TrueType subset)
- **Helvetica Neue Regular** — `HelveticaNeue` (embedded TrueType subset; appears in full-tagline logo files)
- **Unnamed Type 3 font glyphs** — detected as `[none]`, with no reliable font-family identifier available

The font list above is **verified as present in PDF files**, but that does **not** by itself establish a designer-approved typographic system or guarantee which font was intended for each lettering component. The full primary light and black PDFs contain all three named faces; the dark and compact files embed the first two. Some glyphs are represented in unnamed Type 3 subsets.

**Important:** The supplied vector SVG exports consist of scalable glyph outlines, not editable live text. They do not require font installation and should reproduce the approved shapes across printers and browsers. Font files are not included or licensed for redistribution. For new editable typography, get the original branding designer's brand guidelines or editable source document to confirm font roles, weights, tracking/letter spacing, and licenses before replicating the wordmark.
